# CodeAlpha Jenkins Remoting Project

## Objective

This project demonstrates Jenkins Remoting by connecting a remote Jenkins Agent to the Jenkins Controller and executing build jobs remotely.

## Tools Used

- Jenkins LTS
- Java JDK 21
- Windows 11
- PowerShell

## Project Workflow

1. Installed Jenkins.
2. Configured Jenkins Controller.
3. Created a Permanent Agent.
4. Connected the agent using WebSocket.
5. Executed a Freestyle Job on the remote agent.
6. Verified successful build execution.

## Build Output

- Hostname displayed successfully.
- Current user displayed.
- Working directory displayed.
- Build completed successfully.

## Result

The Jenkins Remoting project was successfully completed.
